# Swarm Systems Lab — Website

Marketing/research site for the Swarm Systems Lab: home, news, research notes, media,
publications, team, and open positions.

## Tech stack

- **[TanStack Start](https://tanstack.com/start)** — full-stack React framework (file-based
  routing + SSR), built on **TanStack Router** and **TanStack Query**
- **React 19** + **TypeScript**
- **Vite 8** — dev server and build
- **Tailwind CSS v4** + **shadcn/ui** (Radix primitives) for components
- **Nitro** — server build/runtime adapter
- **Bun** — package manager and task runner

## Getting started

Requires [Bun](https://bun.sh).

```bash
bun install
bun run dev
```

This starts the Vite dev server (default `http://localhost:8080`) with hot reload.

Other scripts (from [package.json](package.json)):

| Command | Purpose |
| --- | --- |
| `bun run dev` | Start the dev server |
| `bun run build` | Production build |
| `bun run build:dev` | Build in development mode |
| `bun run preview` | Preview the production build locally |
| `bun run lint` | Run ESLint |
| `bun run format` | Format the codebase with Prettier |

## Routing

Routes are generated from files in `src/routes/`. Adding a new page:

1. Create `src/routes/my-page.tsx`:
   ```tsx
   import { createFileRoute } from "@tanstack/react-router";

   export const Route = createFileRoute("/my-page")({
     head: () => ({
       meta: [{ title: "My Page — Swarm Systems Lab" }],
     }),
     component: MyPage,
   });

   function MyPage() {
     return <div>Hello</div>;
   }
   ```
2. Add a link to it in [src/components/site-nav.tsx](src/components/site-nav.tsx) if it
   should appear in navigation.
3. `routeTree.gen.ts` is regenerated automatically by the TanStack Router Vite plugin while
   the dev server runs — don't edit it by hand.

## Styling

- Design tokens (colors, fonts, easing) live in [src/styles.css](src/styles.css) under
  `@theme`. The site uses a dark, monospace/"terminal" aesthetic (`--color-accent`,
  `font-display: JetBrains Mono`, etc.).
- UI primitives come from **shadcn/ui** (`src/components/ui/`). To add a new primitive,
  use the shadcn CLI — config is in [components.json](components.json) (`new-york` style,
  `@/` aliases).
- Tailwind v4 is configured via the `@tailwindcss/vite` plugin (no `tailwind.config.js`
  needed).

## Server functions

Server-only logic uses TanStack Start's `createServerFn` — see
[src/lib/api/example.functions.ts](src/lib/api/example.functions.ts) for the pattern.
Server-only config/env reads go in `*.server.ts` files (e.g.
[src/lib/config.server.ts](src/lib/config.server.ts)), which are stripped from the
client bundle.

## Deployment

This is a TanStack Start **SSR** app (see [src/server.ts](src/server.ts)) built via
Nitro. It requires a server runtime to deploy as-is — static hosts like GitHub Pages
need a separate static-export/SPA configuration, which hasn't been set up yet.
