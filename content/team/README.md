# Team

One file per person. Copy `_template.md`, rename it to `firstname-lastname.md`,
and fill it in.

`group` decides which section of the team page the person appears in: `lead`,
`postdoc`, `phd`, `assistant`, `alumni`, or `visitor`. Within a section, people
are ordered by `order` — lower numbers first.

A person gets their own page only if the file has text below the frontmatter.
Alumni and visitors are usually a single line with no text, so they stay on the
team page.

When someone leaves, change their `group` to `alumni` and add a `note` saying
where they went. When a visitor arrives, `group: visitor` and a `note` with the
dates.

Photos go in `photos/`. Square pictures look best.
