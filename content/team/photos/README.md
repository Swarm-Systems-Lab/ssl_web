# Team photos

Group photos of the lab, shown as a carousel at the top of `/team`.

Drop pictures straight in here - there is nothing to list anywhere. They appear
in file-name order, so a number in front keeps them in the order you want:

```
content/team/photos/
  01-2026-05-lab-retreat.jpg
  02-field-day.jpg
```

The caption under each picture comes from the file name, so name them the way
you want them read: `field-day.jpg` becomes "Field day". A date in front,
written `2026-05-12_`, is shown as the date instead of as words. Names a camera
gave the file, like `IMG_4231.jpg`, get no caption rather than a nonsense one.

Files starting with `_` are skipped, so `_originals/` or `_raw-group-shot.jpg`
is somewhere to keep the full-size version.

An empty folder means no carousel: the page starts with the people instead.
