Welcome to our new website! After years on Google Sites we have rebuilt it from scratch. The old one had served its purpose, but it had grown rusty: slow to load, awkward to lay out, and enough of a chore to update that news tended to pile up before anyone got round to posting it.

This one is a static site built with [Astro](https://astro.build) and hosted on GitHub Pages. Every page is plain HTML by the time it reaches you, there is no content management system in the way, and adding a post is a matter of dropping a Markdown file and a few photos into a folder. Everything you can see here - the [news](/news), the [projects](/research), the [papers](/publications), the [people](/team) - is generated from those files.

The source is open, so help yourself if you like it: [github.com/Swarm-Systems-Lab/ssl_web](https://github.com/Swarm-Systems-Lab/ssl_web). It is a research group's site rather than a template, but the ideas are all there and it should be a reasonable place to start if your own group's page is due the same treatment.
